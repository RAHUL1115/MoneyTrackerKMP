# The Kotlin package is `app.moneytracker`, the app id is `in.amrahul.moneytracker`

The published app id is `in.amrahul.moneytracker` (debug builds add `.debug`). The Kotlin package is `app.moneytracker` because `in` is a Kotlin keyword and would have to be escaped in every import. The app id must never change once published, because it identifies the app to the stores and to people's existing installs. The package name can be refactored freely.
